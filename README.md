## 🎯 Sobre a disciplina

A disciplina aborda o desenvolvimento de software utilizando **agentes de IA como ferramentas de engenharia**.

O foco está em aprender a:

* especificar sistemas;
* conduzir agentes de IA;
* revisar código gerado;
* escrever e avaliar testes;
* trabalhar com código legado;
* analisar qualidade e segurança;
* medir resultados;
* publicar software em produção.

> **O agente escreve o código. O desenvolvedor decide, revisa, testa e responde pelo resultado.**

## 🛠️ Ferramentas

A ferramenta de referência da disciplina é o **Claude Code**.

Outras ferramentas podem ser utilizadas, desde que seu uso seja documentado e justificado.

## 📓 Diário

As atividades realizadas com agentes são registradas em:

```text
diario/AAAA-MM-DD.md
```

Cada registro documenta o objetivo, ferramenta utilizada, resultado do agente, alterações realizadas manualmente e aprendizados.
