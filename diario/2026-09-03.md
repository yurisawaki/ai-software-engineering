# Aula 02 (03/09)

**Objetivo.** Implementar um agent loop em Python (< 100 linhas) e avaliar o impacto da degradação da docstring da tool.
**Ferramenta.** Ollama com `llama3.1`, VS Code, ~45 min, 2 iterações.
**O que o agente entregou.** Script funcional de function calling executando em 2 passos para os dois cenários; no segundo teste, com a docstring vaga ("faz uma consulta"), o modelo ainda acionou a tool certa pelo nome do parâmetro, mas afirmou não possuir informações na resposta final.
**O que mudamos à mão.** Ajustamos a tipagem dos schemas e declaramos o laço interativo com condição de saída por `not tool_calls`.
**O que aprendemos.** A docstring atua como contrato semântico: uma descrição vaga faz o laço rodar a ferramenta, mas impede o modelo de confiar no dado retornado para formular a resposta.
